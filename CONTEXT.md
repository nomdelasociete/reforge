# [RE]Cast — context

## Brand

**[RE]Cast**

- **RE** = record (capture the selection)
- **Cast** = cast the transformed text back

## Product

Generic selection → any prompt → overlay preview (word-level diff highlight) → user actions.

- **Enter** = paste / replace the selection with the transformed text
- Also: re-transform, copy, handoff to Omarchy default agent, cancel
- **Presets** = saved prompts (grammar / translate / tone / explain / etc.), not hardcoded modes

## Platform

Omarchy / Hyprland / Wayland plugin.
